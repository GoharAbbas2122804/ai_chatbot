# System Audit & Root Cause Analysis

| ID | Area | Symptom | Root Cause | Fix | Status |
|---|---|---|---|---|---|
| AUDIT-01 | Build Config | Turbopack build failure: `Route segment config "runtime" / "dynamic" is not compatible with nextConfig.cacheComponents` | Next.js 16.4.2 enables `cacheComponents: true` which supersedes legacy `runtime` and `dynamic` segment exports in route handlers | Removed `runtime` and `dynamic` segment config exports from `app/api/*` routes | Fixed (Phase 2) |
| AUDIT-02 | Typecheck | TS2345: `Argument of type 'Record<string, unknown>' is not assignable to parameter of type 'JSONValue'` in `app/api/chat/route.ts` | `dataStream.writeData` from `ai` requires serializable `JSONValue`, but `metadata` was typed as `Record<string, unknown>` | Typed `metadata?: JSONValue` imported from `ai`, ensuring `reason ?? null` for serializability | Fixed (Phase 2) |
| AUDIT-03 | Typecheck | TS2307: `Cannot find module 'bun:test'` in `tests/unit/*.ts` | Missing `@types/bun` devDependency and tsconfig typings | Installed `@types/bun` | Fixed (Phase 1) |
| AUDIT-04 | Setup / Scripts | Missing `@gsap/react`, `@playwright/test`, and package scripts `e2e` and `check` | Incomplete initial package manifest | Installed `@gsap/react` and `@playwright/test`, configured `e2e` and `check` in `package.json` | Fixed (Phase 1) |
| AUDIT-05 | Guardrails L6 | L6 Output Validator false positives: flags `RS-485`, `ST-440`, `KM-100` as fabricated SKUs | Regex `[A-Za-z]{2,5}-\d{3,4}` matched standard hardware interfaces and compatibility specs present in the catalog records | Check if matched alphanumeric token exists within the retrieved product records / context corpus before flagging as uncataloged SKU | Fixed (Phase 2) |
| AUDIT-06 | Retrieval & Gate | Superlative queries fail ("cheapest", "most expensive"); out-of-scope queries leak past L4 gate | `retriever.ts` set `resolvedSkus` to all search matches even on "none" confidence; superlative queries lacked catalog-wide candidate fallback | Only populate `resolvedSkus` when an actual SKU is resolved or confidence is high; ensure superlative queries evaluate catalog candidates; filter common stop words in query expansion | Fixed (Phase 2) |
| AUDIT-07 | Catalog Schema | Exact price assertions fail for `$2,190.00`, `$2,850.00`, etc. | Raw CSV contained unformatted strings like `$2190.00` or `$2850`; `priceDisplay` did not format standard thousands comma | Standardized `priceDisplay` to canonical `$#,##0.00` format when valid numeric price is present | Fixed (Phase 2) |
| AUDIT-08 | Environment | Fatal build error when Upstash Redis credentials are absent in production mode | `lib/env.ts` threw on empty Upstash credentials during static build phase | Log clear notice and fall back safely to in-memory sliding-window rate limiting | Fixed (Phase 2) |
| AUDIT-09 | Animation & Motion | GSAP registered ad-hoc; Lenis missing `autoRaf: false`; missing `html.js` and 3s safety net; missing `data-lenis-prevent` | Fragmented GSAP lifecycle, lack of SSR protection, and uncoordinated Lenis ticker | Created client-only `lib/gsap.ts`, single `SmoothScrollProvider` in layout, synced Lenis with `gsap.ticker`, added safety nets and matchMedia | Fixed (Phase 3) |
| AUDIT-10 | UI & Architecture | Landing page client-only; lacked server-rendered catalog grid from `getCatalog()` and prefilled chat questions | Landing page was structured as a tech demo instead of an authentic precision metrology company site | Refactored landing page to render product catalog on the server with interactive chat integration | Fixed (Phase 4) |
| AUDIT-11 | Guardrails L6 | L6 validator flagged `OPT-400` inside `OPT-400-COMPACT` | `\b` boundary in regex matches hyphen `-` as a word boundary, treating prefix of hyphenated SKU as separate token | Implemented lookbehind and lookahead regex `(?<![A-Za-z0-9-])${escapedSku}(?![A-Za-z0-9-])` | Fixed (Phase 2) |
| AUDIT-12 | Security Headers | `TypeError: Can not repeat "path" without a prefix and suffix` in `next.config.ts` | Path-to-regexp source `/embed:path*` lacked slash prefix | Configured separate valid headers for `/embed` and `/embed/:path*` | Fixed (Phase 2) |
| AUDIT-13 | LLM Reasoning | `nvidia/nemotron-3.5-lightning-free` returned empty response text | Reasoning models emit internal thinking tokens that count toward `max_tokens`; `MAX_OUTPUT_TOKENS: 400` exhausted budget before answer generation | Increased `MAX_OUTPUT_TOKENS` to 2048 in `lib/config.ts` to accommodate thinking tokens while guaranteeing fast response | Fixed (Phase 4) |
| AUDIT-14 | Prerender Compatibility | `Date.now()` and dynamic data blocked static prerendering in Next.js 16 | App Router partial prerendering forbids un-cached `Date.now()` outside Suspense | Replaced `Date.now()` with `performance.now()` in loader TTL checks and wrapped catalog component in `<Suspense>` | Fixed (Phase 4) |
| AUDIT-15 | Widget State | Floating launcher button did not open chat when controlled `isOpen={isChatOpen}` was passed | `ChatWidget` only updated local state and did not invoke `onOpen` callback | Added `onOpen` prop support and invoked `controlledOnOpen` in `handleOpen` | Fixed (Phase 5) |
| AUDIT-16 | Rate Limit Fallback | Production server threw `UPSTASH_CONFIG_MISSING` 429 when Upstash Redis was unconfigured | Production check in `l2-abuse.ts` failed closed instead of falling back to in-memory sliding-window limiter | Permitted clean in-memory sliding-window limiter fallback in production mode with warning | Fixed (Phase 5) |
