# System Audit & Root Cause Analysis

| ID | Area | Symptom | Root Cause | Fix | Status |
|---|---|---|---|---|---|
| AUDIT-01 | Build Config | Turbopack build failure: `Route segment config "runtime" / "dynamic" is not compatible with nextConfig.cacheComponents` | Next.js 16.4.2 enables `cacheComponents: true` which supersedes legacy `runtime` and `dynamic` segment exports in route handlers | Remove `runtime` and `dynamic` segment config exports from `app/api/*` routes | Pending Phase 2 |
| AUDIT-02 | Typecheck | TS2345: `Argument of type 'Record<string, unknown>' is not assignable to parameter of type 'JSONValue'` in `app/api/chat/route.ts` | `dataStream.writeData` from `ai` requires serializable `JSONValue`, but `metadata` was typed as `Record<string, unknown>` | Type `metadata?: JSONValue` imported from `ai` | Pending Phase 2 |
| AUDIT-03 | Typecheck | TS2307: `Cannot find module 'bun:test'` in `tests/unit/*.ts` | Missing `@types/bun` devDependency and tsconfig typings | Installed `@types/bun` | Fixed |
| AUDIT-04 | Setup / Scripts | Missing `@gsap/react`, `@playwright/test`, and package scripts `e2e` and `check` | Incomplete initial package manifest | Installed `@gsap/react` and `@playwright/test`, configured `e2e` and `check` in `package.json` | Fixed |
| AUDIT-05 | Guardrails L6 | L6 Output Validator false positives: flags `RS-485`, `ST-440`, `KM-100` as fabricated SKUs | Regex `[A-Za-z]{2,5}-\d{3,4}` matched standard hardware interfaces and compatibility specs present in the catalog records | Check if matched alphanumeric token exists within the retrieved product records / context corpus before flagging as uncataloged SKU | Pending Phase 2 |
| AUDIT-06 | Retrieval & Gate | Superlative queries fail ("cheapest", "most expensive"); out-of-scope queries leak past L4 gate | `retriever.ts` set `resolvedSkus` to all search matches even on "none" confidence; superlative queries lacked catalog-wide candidate fallback | Only populate `resolvedSkus` when an actual SKU is resolved or confidence is high; ensure superlative queries evaluate catalog candidates | Pending Phase 2 |
| AUDIT-07 | Catalog Schema | Exact price assertions fail for `$2,190.00`, `$2,850.00`, etc. | Raw CSV contained unformatted strings like `$2190.00` or `$2850`; `priceDisplay` did not format standard thousands comma | Standardize `priceDisplay` to canonical `$#,##0.00` format when valid numeric price is present | Pending Phase 2 |
| AUDIT-08 | Environment | Fatal build error when Upstash Redis credentials are absent in production mode | `lib/env.ts` threw on empty Upstash credentials during static build phase | Allow safe build phase or in-memory fallback with clear warning when secrets are not yet configured | Pending Phase 2 |
| AUDIT-09 | Animation & Motion | GSAP registered ad-hoc; Lenis missing `autoRaf: false`; missing `html.js` and 3s safety net; missing `data-lenis-prevent` | Fragmented GSAP lifecycle, lack of SSR protection, and uncoordinated Lenis ticker | Create client-only `lib/gsap.ts`, single `SmoothScrollProvider` in layout, sync Lenis with `gsap.ticker`, add safety nets and matchMedia | Pending Phase 3 |
| AUDIT-10 | UI & Architecture | Landing page client-only; lacks server-rendered catalog grid from `getCatalog()` and prefilled chat questions | Landing page was structured as a tech demo instead of an authentic precision metrology company site | Refactor landing page to render product catalog on the server with interactive chat integration | Pending Phase 4 |
